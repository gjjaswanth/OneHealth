# One Health Assignments

GitHub Pages-ready static site.

## Pages
- `index.html` — homepage with year-based quiz cards
- `2023-one-health-assignments.html` — interactive quiz

## Features
- Shuffled questions
- Shuffled options
- Single-choice, multi-select, and text-answer questions
- Correct / wrong feedback after submit
- Final score summary

## GitHub Pages
Upload these files to the root of your GitHub Pages branch and enable Pages from the repository settings.
